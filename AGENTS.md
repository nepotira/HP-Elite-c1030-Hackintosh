# AGENTS.md — Instruções para agentes de IA neste repositório

Este projeto é um Hackintosh (macOS via OpenCore) para o **HP Elite c1030 Chromebook (Jinlon)**. O dono é brasileiro; escreva em **português do Brasil**.

**Antes de qualquer ação, leia, nesta ordem:**
1. [`docs/BRIEFING_ANTIGRAVITY_MACOS.md`](docs/BRIEFING_ANTIGRAVITY_MACOS.md) — estado atual, problemas abertos e regras do dono.
2. [`docs/REGRAS_DE_VERSIONAMENTO.md`](docs/REGRAS_DE_VERSIONAMENTO.md) — SemVer, commits, tags, releases e rastreamento de erros (**obrigatório**).
3. [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md) e [`docs/HISTORICO_DO_PROJETO.md`](docs/HISTORICO_DO_PROJETO.md) — o que já foi tentado (inclusive o que falhou).
4. [`CHANGELOG.md`](CHANGELOG.md).

**Resumo das regras inegociáveis:** uma mudança por vez e com backup · nunca baixar volume nem desligar efeitos visuais para "resolver" · não fazer além do pedido · hipótese é hipótese (só marcar "resolvido" com confirmação do dono no hardware) · `config.plist` em UTF-8 **sem BOM** e idêntico em `EFI/OC/` e na EFI viva · nunca commitar senhas de Wi-Fi, seriais ou tokens · toda release precisa ter os arquivos anexados e conferidos pela API do GitHub.
